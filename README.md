## 🚀 Getting Started Locally

### Prerequisites

- Node.js 22 or higher
- npm or pnpm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/chakrikapolepalli0610-ship-it/chakrika-portfolio.git
cd chakrika-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:8443`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
